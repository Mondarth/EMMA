EMMA, the Enhanced Module Manager Application, brings package management to Foundry VTT's setup screen, where you can
see every world on your server at once, before launching any of them.

WHAT IT DOES

• Shows your installation as a tree: your worlds, game systems and modules, and what each world last ran with.
• Finds updates for Foundry VTT, its game systems and its modules, and offers only versions that keep every world that
uses them working, as Foundry installs one version of a package for all of them.
• Builds an update plan of installs, updates and uninstalls, explains why it takes each version, and runs it through
Foundry's own installer, offering first to back up the worlds it affects and to take a snapshot.
• Installs new game systems and modules from Foundry's package listing or a manifest URL, with what they require and,
if you want, what they recommend.
• Keeps Foundry's own package buttons from changing what EMMA is managing, until you switch it off.

WHAT YOU NEED

• A Foundry VTT server, version 14 or later, and its administrator password.
• A Mondarth account and an EMMA subscription, through Patreon or bought from Mondarth's accounts, to find updates and
packages to install in EMMA's package catalogue. The installation tree works without one.
• The EMMA module, free on Foundry's package listing, active in the worlds you want EMMA to know in detail.

PRIVACY

EMMA runs only on the servers you activate it on, and asks for each. To find updates, it sends EMMA's package catalogue
the IDs, versions and manifest URLs of the installed game systems and modules, and your sign-in. It sends nothing about
your worlds, your server or you otherwise. See https://accounts.mondarth.com/privacy.
