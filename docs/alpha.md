# EMMA's alpha

The EMMA extension, EMMA on Foundry VTT's setup screen, is an **alpha build**: it is being tested, and changes often.
Its footer says so, and links to this page.

:::{warning}
Use the alpha at your own risk, and only on a test installation: not on a server whose worlds you play. Running a plan
installs, updates and uninstalls packages, and can update Foundry VTT itself. Back up your worlds before you run one.
:::

## What the alpha period means

- **It changes often.** Each release may change how EMMA looks and works, and may bring fixes and new problems alike.
  The window's title gives the version, such as **EMMA - installation (0.1.1)**, so that you can say which one you
  ran.
- **Acknowledge it for each version.** Before EMMA runs its first plan, you must acknowledge that you understand it is
  an alpha: with **I understand** in the footer, or in the plan's confirmation, where the final **Run** stays disabled
  until you do. Running a plan is the only thing EMMA does that changes your installation. The browser remembers your
  answer for that version; a new version asks again.
- **It has limits.** See [Limitations of the alpha](extension.md#limitations-of-the-alpha).

## Where to find help

- **Documentation:** [The browser extension](extension.md) describes the extension and EMMA on the setup screen, and
  [Usage](usage.md) describes the EMMA module in a world.
- **Discord:** ask questions, and tell us what you find, on [EMMA's Discord server](https://discord.gg/uJqFdjNsU4).
- **Issues:** report a problem on [GitHub](https://github.com/Mondarth/EMMA/issues), with EMMA's version and what you
  did.
