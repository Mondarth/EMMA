# Help and feedback

## Before you run a plan

Running a plan installs, updates and uninstalls packages, and can update Foundry VTT itself. EMMA backs up the worlds a
plan affects, and can take a snapshot first (see [The browser extension](extension.md)), but keep your own backups of
the worlds you play, as for any change to a server. See also the extension's [Limitations](extension.md#limitations).

## Which version you ran

EMMA's window gives its version in its title, such as **EMMA - installation (0.15.0)**. Say which one you ran when you
ask for help or report a problem.

## Where to find help

- **Documentation:** [The browser extension](extension.md) describes the extension and EMMA on the setup screen, and
  [Usage](usage.md) describes the EMMA module in a world.
- **Discord:** ask questions, and tell us what you find, on [EMMA's Discord server](https://discord.gg/uJqFdjNsU4).
- **Issues:** report a problem on [GitHub](https://github.com/Mondarth/EMMA/issues), with EMMA's version and what you
  did.
